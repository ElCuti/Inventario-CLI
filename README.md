# Proyecto Python Almacen CLI
 
## 📌 Descripción
Este proyecto es parte de la asignatura de 2º de DAW de programación con Python, libremente he escogido realizar una aplicación CLI de control de almacen

El proyecto poco a poco ira mejorando con el paso de los commits debido a que se desarrolla durante el curso escolar

## 📂 Estructura del Proyecto
El proyecto sigue una estructura limpia para facilitar el mantenimiento y la escalabilidad:

*   `main.py`: Punto de entrada principal de la aplicación.
*   `dataMethod.py`: Contiene todos los metodos que se pueden usar para tratar el almacen.
*   `dataProduct.py`: Contiene la estructura de datos con la que guardo toda la información, mas adelante el almacenamiento se hara mediante arhcivos.
*   `userInterface.py`: Contiene la parte del trato con el cliente de la aplicación.

## 🛠️ Tecnologías y Conceptos Aplicados
*   **Lenguaje:** Python 3.14
*   **Conceptos técnicos:**
    *   Manejo de Estructuras de Datos
    *   Control de Excepciones y Robustez
    *   Validación y Sanitización de Datos (Data Cleansing)
    *   Modularidad y Buenas Prácticas
